# School Specializations Template

> **Purpose:** List your former school's specializations to populate the Curriculum Designer
> **Action:** Fill in the "Your School" column, then I'll build the Curriculum Designer

---

## How to Fill This

1. Look at the "Common Specializations" column
2. Put an **X** in the "Your School?" column for each one offered
3. Add any specializations not listed in the "Other" rows
4. Send this back to me — I'll build the Curriculum Designer
