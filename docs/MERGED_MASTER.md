### Q3: Platform vs. owned system?

**My recommendation: Hybrid approach**

| Feature | Desktop (Access) | Web (Streamlit) | Hybrid |
|---|---|---|---|
| Offline | ✅ Yes | ❌ No | ✅ Local app |
| AI features | ❌ Limited | ✅ Full | ✅ Optional AI |
| Multi-user | ❌ No | ✅ Yes | ✅ Local network |
| Cost | ✅ Low | ⚠️ Hosting | ✅ Low |
| Scalability | ❌ Limited | ✅ High | ✅ Phased |

**Hybrid solution:**
- **Core:** Desktop app (Access/VBA) — owns data, works offline
- **AI layer:** Optional web module — connects when internet available
- **Sync:** Export/import between desktop and web

### Q5: MVP wedge?

**Recommendation: Student Information System (SIS)**

Why:
- Quickest to build
- Most immediate teacher need
- Proves the concept
- Can expand to other modules later

**SIS MVP scope:**
1. Student records (name, class, parent info)
2. Enrollment (new students, transfers)
3. Grades (entry, calculation, reports)
4. Attendance (daily tracking)
5. Basic reports (class list, grade sheet)
